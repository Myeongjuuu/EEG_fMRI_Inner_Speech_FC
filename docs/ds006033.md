# Simultaneous EEG and fMRI on OpenNeuro ds006033

[Dataset](https://openneuro.org/datasets/ds006033/versions/1.0.0) · [Data descriptor](https://pmc.ncbi.nlm.nih.gov/articles/PMC12681749/)

This is a separate workflow from the original ds003626 analysis. Download the full recordings using OpenNeuro. The Git clone contains git-annex pointers. ds006033 has three participants and
two sessions each. EEG is absent for sub-01/ses-01 in the release. Start with sub-02.

## EEG with MNE

From the repository root, use Python 3.11.

```sh
python -m pip install -e ".[dev,fmri]"
python -m inner_speech.ds006033_eeg /path/to/ds006033 results/generated/ds006033/eeg --subject sub-02
```

The published EEG headers name the original acquisition files. The pipeline
rewrites those references in a temporary header without editing the dataset.
A scratch directory with several GB free is needed for the temporary EEG buffer.
Set it with --scratch if needed.

The release has scanner and pulse artifact correction in its BrainVision processing
history. The pipeline resamples, filters, average-references and applies paired
amplitude/flatness QC. It does not fit EOG ICA because this release has no EOG.
Review residual MR artifacts and bad channels before interpreting results.

Use EEG-specific event times. Pair each 1 s word window starting 0.5 s after the
word onset with a 1 s window starting 2 s into the following rest. Compute
alpha-band connectivity across paired trials and multitaper power. Evaluate
eight-word CSP-LDA and CSP-SVM with whole sessions held out within each participant
with two eligible EEG sessions. Chance balanced accuracy for eight classes is
12.5%. The stimulus display overlaps the word period, so classification can
also reflect visual word processing. Rest is inter-trial rest.

## fMRI with fMRIPrep and Nilearn

Run [fMRIPrep](https://fmriprep.org/en/stable/usage.html) on the BIDS dataset with
a FreeSurfer license. This Linux shell example uses Docker, a selected fMRIPrep
image tag in FMRIPREP_IMAGE and absolute host paths.

```sh
docker run --rm -v "$BIDS:/data:ro" -v "$DERIV:/out" -v "$FS_LICENSE:/license.txt:ro" "$FMRIPREP_IMAGE" /data /out participant --participant-label 02 --fs-license-file /license.txt --output-spaces MNI152NLin6Asym:res-2 --slice-time-ref 0.5 --fs-no-reconall --notrack
python -m inner_speech.ds006033_fmri /path/to/ds006033 /path/to/derivatives results/generated/ds006033/fmri --subject sub-02 --session ses-01
```

Check the fMRIPrep reports for motion, registration, brain masks and distortion
before interpreting results. Pass the directory directly containing the
participant folders as the derivatives root. Nilearn downloads the Schaefer
100-parcel atlas in MNI152NLin6Asym. The analysis uses fMRI-specific event times,
samples the design at the midpoint slice-time reference, regresses word/fixation HRFs, motion, white matter, CSF and slow drift, and
excludes non-steady-state and high-motion frames. The output is the ROI Pearson
correlation matrix of residual BOLD during the task run. This estimates background connectivity across the task run. Interpret the
output descriptively per session.

The EEG edges index sensors and the fMRI edges index parcels. A cross-modal
comparison requires a defined hypothesis and verification of event and clock alignment.
